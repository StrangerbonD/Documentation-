JWT Authentication ও Authorization পরিচিতি

পড়ার সময়: ৪ মিনিট
মডিউল: ০১
স্বাগতম! কেন এই ডকুমেন্টেশন?

ওয়েব ডেভেলপমেন্টে বিশেষ করে আধুনিক Backend ও RESTful API তৈরিতে Authentication এবং Authorization সবচেয়ে ক্রুশিয়াল পার্ট। কিন্তু অনলাইনে বেশিরভাগ টিউটোরিয়াল হয় অতিরিক্ত অ্যাকাডেমিক, নয়তো জটিল ভাষায় লেখা।

এই ডকুমেন্টেশনের উদ্দেশ্য খুব সিম্পল: একজন সিএসই স্টুডেন্ট বা ডেভেলপার যেভাবে তার ফ্রেন্ডকে কোনো জটিল কনসেপ্ট সহজে বাংলায় বুঝিয়ে দেয়, ঠিক সেভাবেই আমরা শুরু থেকে শেষ পর্যন্ত পুরো সিকিউরিটি আর্কিটেকচার শিখব।

আমরা কী কী শিখব?

আমরা ধাপে ধাপে একদম ফাউন্ডেশন থেকে শুরু করে প্রোডাকশন-লেভেলের ইমপ্লিমেন্টেশন পর্যন্ত কভার করব:

  • Authentication vs Authorization: পরিচয় যাচাই আর পারমিশন চেক করার ভেতরকার ফান্ডামেন্টাল পার্থক্য।
  • JWT (JSON Web Token) Deep Dive: টোকেনের ভেতরের তিনটি অংশ—Header, Payload ও Signature কীভাবে ক্রিপ্টোগ্রাফিক্যালি কাজ করে।
  • Claims & Identity: User ID, Role বা পারমিশন কীভাবে টোকেনের ভেতরে Claim আকারে সুরক্ষিত রাখতে হয়।
  • ASP.NET Core Web API Integration: Program.cs ফাইলে Dependency Injection ও Middleware কনফিগার করা।
  • Controller & Token Generation: Login DTO ভ্যালিডেশন এবং ক্লায়েন্টে সুরক্ষিত টোকেন রিটার্ন করা।
  • Role-based Authorization: [Authorize(Roles = "Admin")] দিয়ে সুরক্ষিত Endpoint বানানো।
  • Refresh Token মেকানিজম: Access Token এক্সপায়ার হলে বারবার লগইন ছাড়া সেশন সচল রাখার বেস্ট প্র্যাকটিস।

প্রতিটি টপিকের ফরম্যাট

পুরো গাইডে প্রতিটি চ্যাপ্টার একই ধারাবাহিক ৮টি ধাপে সাজানো হয়েছে যাতে পড়তে সুবিধা হয়:

১. এটা কী? কনসেপ্টের একদম সহজ ও প্রাঞ্জল সংজ্ঞা।
২. কেন দরকার? এটা ব্যবহার না করলে কী সমস্যা হতে পারে এবং কেন এটা সমাধান দেয়।
৩. কীভাবে কাজ করে? বিহাইন্ড দ্য সিন বা ইন্টারনাল ফ্লো।
৪. বাস্তব জীবনের উদাহরণ ডেইলি লাইফের কোনো সিচুয়েশনের সাথে মিলিয়ে কনসেপ্ট ফিল করা।
৫. কোড এক্সাম্পল C# এবং ASP.NET Core-এ একদম ক্লিন কোড স্নিপেট।
৬. কোডের লাইন-বাই-লাইন ব্যাখ্যা প্রতিটি মেথড ও ক্লাসের বিস্তারিত বাংলা ব্যাখ্যা।
৭. কমন ভুলগুলো নতুন ডেভেলপাররা সচরাচর যে সব বাগ বা সিকিউরিটি ভুল করে থাকে।
৮. শর্ট সামারি এক নজরে মনে রাখার মতো গুরুত্বপূর্ণ টেক-অ্যাওয়ে।
